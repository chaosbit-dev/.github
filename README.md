# .github

Org-wide defaults for [chaosbit-dev](https://github.com/chaosbit-dev). GitHub reads this repo
specially: nothing here is code.

| Path | What GitHub does with it |
|---|---|
| [`profile/README.md`](profile/README.md) | Shown on the org's page at github.com/chaosbit-dev. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide for any repo without its own. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct. |
| [`SECURITY.md`](SECURITY.md) | Default security policy: how to report a vulnerability privately. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default bug and feature forms; blank issues off, security routed to SECURITY.md. |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default PR description. |

A repo that has its own copy of any of these files uses its own instead.

When a project goes public, add a row for it to the table in `profile/README.md`.
