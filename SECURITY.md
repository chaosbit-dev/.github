# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the affected repository's **Security** tab and choose
**Report a vulnerability**. That opens a private advisory only the maintainers can see.

If that isn't available, email **security@chaosbit.dev**.

Please include:

- the repository and version or commit,
- what an attacker can do, and what they need first,
- steps to reproduce, or a proof of concept.

## What to expect

These projects are maintained in spare time, so timelines are best-effort:

- acknowledgement within **7 days**,
- an initial assessment within **14 days**,
- a fix or mitigation plan agreed with you before any public disclosure.

We're happy to credit you in the advisory unless you'd rather stay anonymous.

## Supported versions

Only the latest release, or `main` where there are no releases, gets security fixes.
